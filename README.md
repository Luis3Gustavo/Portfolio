# Página Pessoal — Portfólio Web

Página Pessoal (Portfólio Web), desenvolvido em duas versões com o mesmo conteúdo:

1. **Bootstrap** — `bootstrap/index.html`
2. **Bulma** — `outro-framework/index.html`

As duas versões utilizam HTML, CSS e JavaScript e possuem layout responsivo e alternância entre tema claro e tema escuro.

## Estrutura

```text
pagina-pessoal/
├── bootstrap/
│   ├── index.html
│   └── assets/
│       ├── css/
│       │   └── style.css
│       ├── js/
│       │   └── script.js
│       └── img/
├── outro-framework/
│   ├── index.html
│   └── assets/
│       ├── css/
│       │   ├── style.css
│       │   └── theme-dark.css
│       ├── js/
│       │   └── script.js
│       └── img/
├── index.html
├── README.md
└── LICENSE
```

## Observação sobre equivalência

As duas versões apresentam o mesmo conteúdo e a mesma organização geral:

- apresentação;
- sobre mim;
- habilidades;
- projetos;
- contato;
- tema claro/escuro.

A principal diferença estrutural é a utilização do framework CSS:

- Bootstrap na primeira versão;
- Bulma na segunda versão.
